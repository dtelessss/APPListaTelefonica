## Funcionalidades principais
- Todos os utilizadores podem consultar a lista telefónica pública;
- Deve ser possível o utilizador registar-se para criar a sua lista telefónica privada;
- O(s) administrador(es) podem editar a lista telefónica pública e também a sua própria lista telefónica privada;
- Os contactos na lista telefónica privada devem poder ter identificadores: Ex: Fornecedores (para contactos de fornecedores), Data Center (para contactos com o datacenter), etc...;
- Cada utilizador registado/administrador deve poder criar os seus identificadores;
- Deve existir um mecanismo para a criação da primeira conta de administração;
